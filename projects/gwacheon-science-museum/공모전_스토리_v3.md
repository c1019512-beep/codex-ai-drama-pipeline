# 화성까지는 이쪽입니다 — 공모전 맞춤 스토리 (v3)

## 1. 공모전 맥락 정리
- **주최/명칭:** 2026 국립과천과학관 AI 활용 숏폼 공모전 (접수 ~2026.10.16 금)
- **핵심 조건:** 과학관이 제공한 **오프닝 숏폼에서 이어지는** 30초 이내 AI 영상
- **우리 부문:** 자유주제 — "국립과천과학관을 소재로" / 예시: 기존 전시품의 색다른 변신 · 새로운 전시공간에 대한 상상 · 개인적인 관람 경험 공유
- **오프닝이 던진 질문:** 하늘에서 **리본으로 포장된 과학관(선물 상자)**이 내려앉고, 그 아래로 **흰 발가락의 주황 고양이 발**이 삐져나온다 → 카메라가 발로 다가가며 **암전**.
  → 시청자에게 남는 질문은 **"이 선물 상자 안에는 뭐가 있을까? 저 고양이는 누구지?"**
- **포스터 키비주얼:** 아기 고양이가 선물 상자(과학관)를 열어보는 장면 → 공모전 전체 컨셉은 **"과학관 = 열어보는 선물, 고양이 = 첫 관람객"**
- **예시 영상(참고):** 암전 → 상자 안 = 하얀 원형 전시관 → 실제 전시관(과학탐구관·미래상상SF관·천체투영관 등)이 차례로 변신, 관 이름을 세로 자막으로. 36초라 규정 초과, 캐릭터 없음.

## 2. 우리 작품의 차별점
예시는 "공간 몽타주", 우리는 **"고양이가 선물 상자 속 과학관을 직접 열어보는 이야기"**.
오프닝의 질문("상자 속엔 뭐가?")에 **캐릭터와 대사로 답한다** → 오프닝과의 연결성 + 스토리 + 실제 전시관 홍보를 한 번에.

## 3. 로그라인
> 선물 상자 속에서 깨어난 아기 고양이 '누룽지'. 상자가 열리자 그 안은 국립과천과학관이었고, 안내 로봇 '과니'가 첫 관람객을 맞는다. "보호자 미확인… 예외 처리합니다." 우주복을 입고 도착한 곳은 화성.
> **과학관은, 열어볼수록 더 큰 선물이다.**

## 4. 컷 구성 (29.8초, 오프닝 암전에서 바로 이어짐)

| 컷 | 시간 | 장면 | 대사/자막 | 영상 |
|---|---|---|---|---|
| **C1 상자 속** | 0–7.5 | 암전(오프닝 끝) → 어둠 속 호박색 눈 두 개 → 리본이 풀리며 상자 뚜껑 틈으로 따뜻한 빛 → 누룽지가 뚜껑을 머리로 밀고 고개를 내밀자, 상자 밖은 **과학관 로비** | 과니(화면 밖): "화성까지는 이쪽입니다." | 🆕 **새로 생성** |
| **C2 로비** | 7.5–15 | 과니가 첫 관람객을 발견 → 삐빅 → 유리문 가리킴 → 누룽지 출발 | 과니: "보호자 미확인… 예외 처리합니다." | ♻️ V2 take2 |
| **C3 체험존** | 15–22.5 | 우주복 입고 등장 → 화성관 문으로 | 과니: "안전장비… 착용 완료." · 세로 자막 **스페이스월드** | ♻️ V3 take2 |
| **C4 화성** | 22.5–29.8 | 로버 옆 "냥!" → 돔과 화성 공개 | 과니(화면 밖): "…내일도 이쪽입니다." · 자막 **오늘의 관람객: 1묘** → 엔딩 카드 | ♻️ V4 take2 |

**엔딩 카드(마지막 1.5초):** `열어볼수록, 국립과천과학관` + 작은 글씨 `화성까지는 이쪽입니다 →`

### 오프닝과의 연결 장치 3개
1. **암전 → 어둠 속 눈**: 오프닝 마지막 검은 화면에서 끊김 없이 시작
2. **고양이 발 = 누룽지**: 오프닝의 주황 털+흰 발가락 = 누룽지 디자인(A 시트)과 동일
3. **선물 상자 모티브**: 흰 상자 + 검은 리본(오프닝 그대로)이 C1에서 풀리며 "선물을 연다"

### 바뀌는 점 (v2 대비)
- V1(로비①)을 빼고 **C1 상자 오프닝 컷**으로 교체 → V1의 대사 "화성까지는 이쪽입니다."는 C1 화면 밖 목소리로 이동 (제목 콜백 유지)
- 세로 자막(전시관 이름) 추가: 예시 영상의 문법을 차용해 실제 관 이름 노출
- 엔딩 카드에 공모전 메시지(과학관 = 선물) 한 줄 추가
