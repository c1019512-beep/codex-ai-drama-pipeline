# 화성까지는 이쪽입니다 — Veo 영상 프롬프트 (8초 × 4컷, 세로 9:16)

Gemini 영상(Veo)은 한 번에 8초까지라 대본 S#1~S#3를 4컷으로 나눴다. 총 32초 → 컷 이음새마다 0.5~1초 다듬어 30초로 조립.

| 컷 | 대본 | 첨부 이미지 (순서대로) |
|---|---|---|
| V1 로비① | S#1 앞부분 | `A_nurungji` · `C_gwani` · `E1_lobby` |
| V2 로비② | S#1 뒷부분 | `A_nurungji` · `C_gwani` · `E1_lobby` |
| V3 체험존 | S#2 | `B_nurungji_suit` · `C_gwani` · `E2_suit_room` |
| V4 화성관 | S#3 | `B_nurungji_suit` · `E3_mars_hall` |

공통 원칙
- 매 컷 세로 9:16, 8초
- 배경음악·자막·화면 글자 없음 (BGM과 "오늘의 관람객: 1묘"·타이틀은 조립 후 얹음)
- 과니 목소리 문장은 4컷 모두 한 글자도 바꾸지 않음
- 고양이와 로봇이 같이 나오는 컷엔 크기 문장 필수

## V1 — 로비① (0~8초)
```
첨부 이미지: 1) 아기 고양이 누룽지 2) 안내 로봇 과니 3) 과학관 로비. 세 이미지의 고양이·로봇 생김새와 로비 공간을 그대로 사용.
세로 9:16, 8초. 고급 실사 CGI, 따뜻한 늦은 오후 햇빛, 얕은 심도, 부드러운 시네마틱 카메라. 잔잔한 코미디 톤.
폐관 직전 텅 빈 로비, 사람 없음. 과니는 화면 오른쪽, 유리 전시관 문 가까이에서 왼쪽을 향해 서 있다. 누룽지는 화면 왼쪽 대리석 바닥에 앉아 과니를 올려다본다. 로봇 키가 고양이의 약 두 배. 둘은 컷 내내 좌우 자리를 바꾸지 않는다.
0~1초: 두 캐릭터가 제자리에 있는 넓은 고정 샷.
1~4초: 과니가 빈 로비를 향해 말한다. 과니 목소리: 밝고 공손한 합성음, 살짝 금속성 울림, 일정한 안내원 말투. 대사(이것만): "화성까지는 이쪽입니다."
4~8초: 누룽지가 과니 가슴 화면 속 빨간 화성을 향해 앞발 하나를 든다. 작고 높은 "냥" 한 번. 과니의 얼굴 화면이 천천히 고양이 쪽으로 내려간다.
대사는 따옴표 안 문장만, 고양이는 울음 한 번만. 배경음악 없음, 자막 없음. 소리: 로비 공기음, 로봇 모터 소리.
```

## V2 — 로비② (8~16초)
```
첨부 이미지: 1) 아기 고양이 누룽지 2) 안내 로봇 과니 3) 과학관 로비. 생김새와 공간 그대로.
세로 9:16, 8초. 고급 실사 CGI, 따뜻한 늦은 오후 햇빛, 얕은 심도, 부드러운 시네마틱 카메라. 잔잔한 코미디 톤.
텅 빈 로비, 사람 없음. 과니는 화면 오른쪽 유리 전시관 문 옆, 누룽지는 화면 왼쪽 바닥에서 과니를 올려다보는 상태로 시작. 로봇 키가 고양이의 약 두 배.
0~3초: 과니의 파란 눈이 두 번 깜빡이고 짧은 "삐빅" 소리. 한 박자 멈춘 뒤 천천히 말한다. 과니 목소리: 밝고 공손한 합성음, 살짝 금속성 울림, 일정한 안내원 말투. 대사(이것만): "보호자 미확인… 예외 처리합니다."
3~5초: 과니가 오른팔을 뻗어 유리 전시관 문을 가리킨다.
5~8초: 누룽지가 꼬리를 꼿꼿이 세우고 그 문을 향해 총총 걸어가다가, 한 번 과니를 뒤돌아본다.
대사는 따옴표 안 문장만. 배경음악 없음, 자막 없음. 소리: 삐빅, 로봇 팔 모터 소리, 대리석 위 작은 발소리.
```

## V3 — 우주복 체험존 (16~24초)
```
첨부 이미지: 1) 우주복을 입은 아기 고양이 누룽지 2) 안내 로봇 과니 3) 우주복 체험존. 고양이 얼굴·우주복 디자인·로봇·공간을 그대로.
세로 9:16, 8초. 고급 실사 CGI, 따뜻한 스포트라이트, 얕은 심도, 부드러운 시네마틱 카메라.
텅 빈 체험존, 사람 없음. 화면 왼쪽 유리 탈의 부스 문이 이미 스르륵 열리는 중. 과니는 부스 오른쪽에서 고양이를 보며 기다린다. 로봇 키가 고양이의 약 두 배.
0~3초: 우주복과 투명 유리 헬멧을 완벽히 갖춘 누룽지가 고개를 들고 당당한 걸음으로 부스에서 걸어 나온다. 낮은 고양이 눈높이 카메라.
3~4초: 과니가 작게 고개를 끄덕인다. 과니 목소리: 밝고 공손한 합성음, 살짝 금속성 울림, 일정한 안내원 말투. 대사(이것만): "안전장비… 착용 완료."
4~8초: 컷 전환. 뒤에서 낮게 따라가는 카메라. 누룽지가 돌아서서 안쪽 출입구를 향해 걷는다. 출입구 너머로 붉은 화성 지형과 로버가 점점 커진다. 과니는 오른쪽 한 걸음 뒤에서 따라온다.
중요: 어느 각도에서도, 바로 뒤에서 봐도 흰 우주복과 생명유지 팩이 고양이 등과 몸 전체를 덮고 있다. 털이 보이는 건 주황 링 구멍으로 나온 꼬리뿐. 우주복 디자인은 첨부 이미지와 똑같이 유지.
배경음악 없음, 자막 없음. 소리: 부스 문 공기 빠지는 소리, 우주복 천 스치는 소리, 작은 패딩 발소리, 로봇 바퀴 소리.
```

## V4 — 화성 전시관 (24~32초, 마지막 컷)
```
첨부 이미지: 1) 우주복을 입은 아기 고양이 누룽지 2) 화성 전시관. 고양이 얼굴·우주복 디자인·공간을 그대로.
세로 9:16, 8초. 고급 실사 CGI, 돔 천장의 따뜻한 스포트라이트, 얕은 심도, 부드러운 시네마틱 카메라.
텅 빈 전시관, 사람 없음, 화면에 보이는 캐릭터는 고양이 하나. 로봇은 화면에 나오지 않는다.
0~3초: 고양이 눈높이 카메라가 옆에서 따라간다. 누룽지가 붉은 흙 위를 걸어 로버 앞바퀴 옆을 지나가며 작은 발자국을 남긴다. 발걸음마다 붉은 먼지가 살짝 일었다 가라앉는다.
3~4초: 멈춰 서서 헬멧을 로버 카메라 쪽으로 기울이고 밝게 "냥!" 한 번 (헬멧 안이라 살짝 울림).
4~8초: 카메라가 천천히 뒤로 빠지며 위로 올라간다. 돔 천장, 둥근 조명 링, 꼭대기의 커다란 화성이 드러나고, 누룽지는 넓은 붉은 대지 아래쪽 가운데에 앉아 작은 점이 된다. 마지막 2초는 정지된 와이드 샷.
7초쯤 화면 밖 목소리만: 과니 목소리: 밝고 공손한 합성음, 살짝 금속성 울림, 일정한 안내원 말투. 부드럽게, 대사(이것만): "…내일도 이쪽입니다."
중요: 어느 각도에서도 흰 우주복과 생명유지 팩이 고양이 몸 전체를 덮고 있고 털은 꼬리만 보인다. 로버는 움직이지 않는다.
배경음악 없음, 자막 없음, 화면 글자 없음. 소리: 자갈 밟는 발소리, 넓은 홀 울림.
```
