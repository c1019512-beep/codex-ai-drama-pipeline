# 화성까지는 이쪽입니다 — 1부 트리트먼트 (v1)

## 로그라인
폐관 10분 전 국립과천과학관. 3년째 똑같은 안내 멘트만 반복하던 안내 로봇 '과니' 앞에 보호자 없는 관람객이 나타난다. 키 20cm, 털 색 치즈, 말 대신 "냥". 규칙대로라면 돌려보내야 하지만, 이 손님이 가리키는 곳은 하필 화성이다.

## 세계관 / 네이밍
**안내 로봇: 「과니」**
- '과천'의 '과' + 안내원의 '안니(언니)' 발음. 이름부터 "안내하려고 태어난 존재"
- 가슴 화면에는 늘 화성 그림과 화살표(→)가 떠 있다 (기존 영상 속 디자인 그대로). 이 화살표가 작품 전체의 콜백 장치
- 성격: 규칙 덕후. "어린이 관람객은 보호자와 동반해야 합니다"를 하루 400번 말한다. 사실은 한 번도 전시관 안쪽까지 따라 들어가 본 적이 없다
- (후보안: 과니 / 별순이 / 안내 3호)

**아기 고양이: 「누룽지」**
- 치즈색 털이 누룽지처럼 군데군데 진하게 탔다. 과니가 털 색을 스캔하고 "누룽지 색상 코드와 98% 일치"라며 붙인 이름
- 성격: 움직이는 건 전부 장난감. 로봇 화면 속 화성도, 탐사 로버의 카메라 눈도 장난감이다
- (후보안: 누룽지 / 치즈 / 마루)

**공간: 국립과천과학관**
- 로비 → 우주복 체험존 → 화성 전시관 → 돔 천장(별빛). 실제 과학관 동선을 그대로 쓰지 않고 '관람객 한 명을 위한 투어'로 재구성
- 전시관 이름과 내부 배치는 창작한 것이다 (실제 전시와 다를 수 있음)

## 1부 씬 구성 (4컷 × 약 15초, 총 1분)

### S1. 로비 — 폐관 10분 전 ✅ 기존 영상 사용 가능 (22ec9180 / 888ef9db)
- 과니가 텅 빈 로비에서 혼자 안내 멘트를 한다. "화성까지는 이쪽입니다." 듣는 사람은 없다
- 바닥에서 "냥". 누룽지가 과니 화면 속 화성을 잡으려고 앞발을 든다 (웃긴 포인트 ①)
- 과니: "어린이 관람객은 보호자와 동반해야 합니다… 보호자를 확인할 수 없습니다." 오류음 3초 뒤: "…예외 처리합니다." 처음 써보는 단어다
- 과니가 팔을 뻗어 화살표 방향을 가리키고, 누룽지가 그쪽으로 총총 걸어간다

### S2. 우주복 체험존 ✅ 기존 영상 사용 가능 (37940cb6)
- 과니: "화성 대기의 95%는 이산화탄소입니다. 안전장비를 착용하세요." 사람용 우주복 앞에서 3초간 정적 (웃긴 포인트 ②)
- 컷 전환. 누룽지가 몸에 딱 맞는 아기 우주복과 헬멧을 입고 당당하게 걸어 나온다. 어떻게 입었는지는 끝까지 설명하지 않는다 (웃긴 포인트 ③)
- 헬멧 안에 수염이 눌린다. 누룽지가 고개를 갸웃한다. 과니: "착용 상태… 양호."
- 문이 열리고 붉은 화성 지평선이 보인다. 누룽지가 꼬리를 세운다

### S3. 화성 전시관 ✅ 기존 영상 사용 가능 (c3ca8557)
- 붉은 흙, 돔 천장에 뜬 화성. 탐사 로버 전시물 옆으로 누룽지가 걸어간다
- 로버의 카메라 머리가 누룽지를 따라 천천히 돈다. 둘이 마주 본다 (웃긴 포인트 ④: 전시물이 움직인 걸 아무도 모른다)
- 누룽지가 로버 바퀴 자국 위에 자기 발자국을 남긴다. 과니는 처음으로 전시관 '안쪽'에 서 있다

### S4. 돔 아래 — 폐관 🆕 새로 생성 필요
- 조명이 하나둘 꺼지고 돔 천장에 별이 켜진다
- 누룽지는 로버 위에서 헬멧을 쓴 채 잠들어 있다
- 과니의 화면 속 화살표(→)가 처음으로 사라지고, 대신 한 줄이 뜬다: "오늘의 관람객: 1묘"
- 과니가 안내 멘트 대신 처음으로 자기 말을 한다: "…내일도 이쪽입니다."
- 마지막 1초: 아무도 없는 로비 쪽을 향해, 로버의 카메라 불빛이 깜빡인다

## 심어둔 떡밥 (2부용)
- **로버가 살아 있다?** S3에서 고개를 돌리고 S4에서 불빛이 깜빡인다. 2부에서 로버가 "두 번째 관람객"이 될 수 있다
- **"예외 처리합니다"**: 과니가 처음 써본 단어. 2부에서 과학관 관리자에게 들키는 위기 때 다시 쓰이면서 의미가 뒤집히게 할 수 있다
- **누룽지는 어떻게 우주복을 입었나**: 끝까지 미스터리로 남겨 러닝 개그로 쓰거나, 2부에서 체험존 직원 캐릭터를 등장시켜 회수한다
- **화살표(→)**: 1부 마지막에 사라졌다. 2부에서는 누룽지가 꼬리로 화살표 모양을 만들어 과니를 안내하는 역전 구도로 쓸 수 있다
- **천체관 / 천문대**: S4의 별빛 돔은 2부 무대(천체관) 예고 역할을 한다
